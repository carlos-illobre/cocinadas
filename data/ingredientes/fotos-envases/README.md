# Fotos de envases

Esta carpeta contiene las imágenes de los envases de los productos registrados.

Cada ficha de ingrediente debe vincular su foto mediante una ruta relativa, por ejemplo:

`![Envase del producto](../fotos-envases/nombre-del-producto.jpg)`

Convención de nombres:

- `producto-marca-presentacion-frente.jpg`
- `producto-marca-presentacion-dorso.jpg`
- `producto-marca-presentacion-informacion-nutricional.jpg`
