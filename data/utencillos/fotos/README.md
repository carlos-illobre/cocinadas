# Fotos de utensilios

Todavía no hay fotos: sacarlas y guardarlas acá.

Convención de nombres, igual que en `data/ingredientes/fotos-envases/`:

- `<identificador-de-la-ficha>-frente.jpg` (la principal, sobre fondo claro y sin sombras fuertes)
- `<identificador-de-la-ficha>-detalle.jpg`, `-tapa.jpg`, `-caja.jpg` para tomas secundarias

Ejemplos: `wok-eternity-copper-30cm-frente.jpg`, `jarro-slow-fire-2l-frente.jpg`, `cuchara-madera-ferpa-60cm-frente.jpg`.

Después de guardar la foto, enlazarla desde la ficha del utensilio con `![nombre](fotos/archivo.jpg)`. La app usa la primera imagen enlazada en la ficha; el nombre del archivo es solo para encontrarla a mano.

Prioridad para la primera tanda (los que usa la receta del spaghetti): wok, jarro hervidor, cuchara de madera, pinza parrillera, balanza, tabla verde, cuchillo chef 8308, rallador zester, rollo de cocina, cocina.
